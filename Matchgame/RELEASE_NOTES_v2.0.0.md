# 桌面版 2.0.0 更新说明

命令行和raylib两个C入口共用算法；本次重点是课程作业中的真实算法过程展示，不新增道具或案例模块。

## 相比1.0

- 两版独立选择10×10、20×15、30×20（列×行）与k=3/4/5。
- 统一昵称设置、关卡、固定每格10分、提示、无解重新生成、用时和最终统计。
- 同一阶段执行器负责交换、匹配、交叉去重、消除计分、下落、补充、再检测和结算。
- 命令行增加演示模式：每阶段回车推进，含回合结束；Q取消未完成回合并恢复棋盘和成绩。提示及反馈在清屏后保留。
- raylib增加设置页、下一步、自动播放、暂停、重开和结果页。
- raylib改为1600×1000逻辑布局，放大格子、文字和按钮；支持等比窗口缩放、正确点击映射及Windows工作区适配。
- 保留main.c、game.c、game.h、MatchGameRaylib/gui_main.c四个业务文件和UTF-8注释。

## 下载运行

Windows x64运行包已静态链接C运行库，raylib包也静态链接现有raylib。无需安装VS2022或raylib；图形版要求OpenGL 3.3兼容显卡驱动，中文使用本机Windows系统TTF字体，不打包或下载字体。

解压命令行ZIP后运行Matchgame.exe；建议从PowerShell启动以保留最终成绩。
解压raylib ZIP后运行MatchGameRaylib.exe。详细步骤见README.md。SHA256SUMS.txt用于核验下载包。

## 验证

Release/Debug x64构建通过；核心、三档×三k×30种子共270组初始化、有效边界、域外哨兵、交叉去重、重力/补充、取消、换关、重开、正常/单步一致性测试通过。
命令行九种尺寸/k组合和完整演示停留通过；raylib三档单步/暂停/取消/重开/自动播放、缩放点击和工作区适配通过。发布前另验证解压后的真实运行包。

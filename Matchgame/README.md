# 消消乐 2.0 · C 语言算法展示课程作业

本目录的命令行版与 raylib 版共用一套二维数组算法。重点是展示“交换、检测、消除、下落、补充、连锁和结算”的真实过程，未增加案例模块或游戏道具。

## 运行

使用 VS2022 打开本目录的 Matchgame.sln，选择 Debug 或 Release、x64，生成解决方案。输出在 x64/Debug/ 或 x64/Release/：

- Matchgame.exe：命令行入口。
- MatchGameRaylib.exe：raylib 图形入口。

项目需要 VS2022 v143 编译工具、Windows SDK，以及本目录已有的 raylib-sdk。命令行使用 UTF-8 输入输出；图形界面读取本机 Windows Fonts 目录的黑体 TTF 字体，不下载或分发字体文件。

本次桌面版本为2.0.0，源码发布在独立分支 release/desktop-v2.0。两个运行包分别对应 console-v2.0.0 和 raylib-v2.0.0；既有1.0标签、发布记录和网页版保持原样。

## 命令行使用方法

开始时依次输入昵称、棋盘档位、消除长度 3/4/5、运行模式。棋盘大小与 k 独立选择：

- 1 小型：10×10（10列、10行）。
- 2 中型：20×15（20列、15行）。
- 3 大型：30×20（30列、20行，原棋盘规模）。

然后选择运行模式：

- 1：正常模式，自动执行整回合，显示最终结果。
- 2：演示模式，每阶段显示棋盘与说明，等待回车后才执行下一阶段。

正常操作使用「行 列 方向」，例如 3 5 D，表示第3行第5列与右边物品交换。W/A/S/D 为上/左/下/右，大小写均可。行列范围由当前尺寸决定；小型不能输入第11行或第11列，边缘向外交换也会被拒绝。

稳定棋盘时的命令：H 提示有效交换，R 原设置重开，Q 结束本局。演示回合进行中只接受回车或单独的 Q。退出未完成回合会恢复操作前棋盘与成绩。结束界面可输入 R 重开、N 修改设置或 Q 退出程序。

每个阶段（包括回合结束）都会停留。回合结束后按回车返回操作，或输入 Q 直接结算；这时回合已经提交，不会撤销得分。提示、错误信息和回合摘要在清屏后仍保留，直到下一条操作反馈替换它们。

阶段显示：

- 交换：显示两个坐标及交换前的数字。
- 检测：用 [数字] 标出匹配，列出横纵连续段、重复数和去重数量；此时尚未消除。
- 消除：空位用点号显示，说明本轮得分和累计消除数量。
- 下落：保留顶部空位，列出真实物品起终点。
- 补充：显示新生成的位置与数字。
- 再检测：说明是否继续连锁，空检测不增加连锁轮数。
- 结算：检查关卡和有效操作，必要时重新生成可玩棋盘，最后显示回合汇总。

演示打印长列表时最多展示前8项，所有受影响位置仍反映在当前有效棋盘中。提示只读，不改变棋盘、分数或随机序列。

## raylib 使用方法

设置页输入昵称，退格删除，独立选择小型/中型/大型、k=3/4/5、正常模式或算法演示，点击开始或按 Enter。默认大型，游戏页和结果页均显示列×行尺寸。

界面以1600×1000为逻辑布局，初始客户区最大1600×1000，读取当前Windows显示器工作区并扣除实际窗口边框，在可用区域内居中，避开任务栏。可以拖动窗口边缘调整大小或最大化；布局等比缩放并居中，外侧留白不接收点击。最大棋盘格子从原27扩大到36逻辑像素，中型为48，小型为60；数字、按钮与算法说明同步放大。小棋盘在左侧区域居中，不拉伸变形。

点击一个格子选中，再点击相邻格子交换。再次点击同格取消选择；点击不相邻格子切换选择。白框为选中，黄框为检测标记，蓝框为提示位置。算法面板显示阶段、匹配段、去重、连锁轮数、得分与真实下落/补充记录。

演示模式默认单步。按钮及快捷键：

- 下一步 / Space：只执行下一个算法阶段。
- 自动播放 / A：按阶段自动推进；停止自动后停留在当前阶段终态。
- 暂停/继续 / P：暂停计时和播放。
- 提示 / H：仅在稳定且未暂停时提供有效交换。
- 重开 / R：恢复未完成回合，再按原设置开始新局。
- 结束本局：显示结算；结果页可重开或返回修改设置。
- 关闭窗口或 Esc：退出程序。

正常模式自动推进，并使用短暂移动效果说明交换、下落和补充。显示代码只读取核心的前后棋盘与变化记录，不再次执行随机生成或计分。动画、活动回合和暂停期间不接受新的棋盘交换。窗口失焦自动暂停，返回后点击继续。

## 统一规则

当前棋盘可为10×10、20×15、30×20（列×行），九种数字；连续达到 k 才消除整串。横纵交叉只清除与计分一次。每个物品固定10分，连锁不加倍率。累计300/700分进入后续关卡，1200分获胜。进入新关卡保留昵称、棋盘大小、k、分数和用时，重新生成稳定可玩棋盘。重开保留大小和k，返回设置可重新选择。

棋盘大小是规模参数，不额外改变计分或绑定k。数组仍按最大20行30列分配，Game.rows/cols定义有效范围；检测、下落、补充、提示和坐标校验仅处理该范围。未启用区域不参与消除。

初始化、换关及无解时的重新生成，都保证没有即时消除且至少有一次有效交换。随机生成最多尝试32次；未成功则用稳定周期棋盘植入保证可交换的图案。这是初始化算法的有界兜底，不是独立的演示案例。

用时统计正常操作与自动播放；演示单步等待、主动暂停和图形窗口失焦不计入。结束冻结时间，重开归零。统计仅记录完整回合的有效交换数、累计消除数和最大连锁；取消不保留半个回合的成绩。

## 四个文件与算法复杂度

| 文件 | 主要职责 |
| --- | --- |
| game.h | 状态、匹配段、标记数组、阶段与变化记录 |
| game.c | 生成、交换、扫描、去重、计分、下落、补充、阶段推进与计时 |
| main.c | 严格输入、命令行棋盘与阶段解释 |
| MatchGameRaylib/gui_main.c | 设置、图形显示、鼠标及演示控制 |

设当前有效行数为 R、列数为 C，最大容量为 M=20×30。为便于手动学习，记录数组保留最大容量O(M)，下列O(RC)描述实际有效扫描；清零整个匹配记录另有O(M)开销。

- 匹配检测：分别扫描有效行列，并统计标记数组，扫描时间 O(RC)，实际匹配段不超过O(RC)；当前静态存储及清零为O(M)。
- 重力：每列从下往上读取，writeRow 指向下一写入位置，时间 O(RC)，保持原有顺序；实际轨迹最多O(RC)，预留数组容量O(M)。
- 补充：遍历空位并随机生成，时间 O(RC)。
- 提示：每格只模拟右、下两个方向，局部连续段检查最坏 O(R+C)，扫描时间 O(RC(R+C))，开始复制状态另需O(M)；使用局部棋盘副本，不修改原状态。
- 连锁：实际轮数为 L 时，基本扫描为O(LRC)；当前实现的记录清零和快照保存还需O(LM)。结算后的可用操作检测另按提示复杂度计算。异常超过100轮时恢复原局面并报告，不假装结算成功。

beginRound 仅校验请求和保存快照；advanceRound 每次执行一阶段；两个入口均调用它。绘制不推进算法。playMove 是正常模式的共用包装，因此正常与演示的规则及结果一致。

# 消消乐 raylib 图形版 1.0.0

初始 C 语言 raylib 图形版本，面向 Windows x64。

- 彩色数字棋盘，鼠标点击两个相邻格子交换。
- 支持选中边框、取消选择、不相邻时重新选择及无效交换回退。
- 展示交换、消除、下落、补充及连锁动画。
- 共享命令行版的消除、计分、计时和关卡规则。

下载 `Matchgame-raylib-v1.0.0-windows-x64.zip`，解压并运行 `MatchGameRaylib.exe`。无需安装 raylib，包内包含操作说明和 raylib 许可证。需要支持 OpenGL 3.3 的显卡驱动。

本版昵称固定为 `DemoPlayer`，k 固定为 3；尚未提供设置界面、提示、无解检测或自动洗牌。Esc 或关闭窗口退出。

该包使用 VS2022 Release x64、静态 C 运行库和静态 raylib 构建。源码保存开发时使用的 raylib 6.1-dev 快照，不依赖再次下载上游 master。

验证：构建成功；窗口和 OpenGL 初始化成功，正常关闭退出码为 0；未执行鼠标动画及完整通关的自动化验收。图形坐标转换及第三方源码仍有编译警告。

本次发布使用独立分支 `release/desktop-v1.0`，不修改 main 或可视化开发分支。

# 消消乐命令行版 1.0.0

初始 C 语言命令行版本，面向 Windows x64。

- 20×30 棋盘，九种物品，支持 k=3、4、5。
- 输入昵称，以“行 列 WASD”交换，Q 退出。
- 支持横纵消除、交叉去重、重力下落、随机补充和自动连锁。
- 每个物品 10 分，包含累计计时及 300/700/1200 分关卡目标。

下载 `Matchgame-console-v1.0.0-windows-x64.zip`，解压并运行 `Matchgame.exe`。包内包含操作说明。源码见本标签的 `Matchgame/` 目录。

该包使用 VS2022 Release x64 和静态 C 运行库构建，不包含 VS 缓存或调试文件。

验证：构建成功；k=3/4/5、错误 k 重试、非法坐标/方向、Q 退出检查通过。现有回合输入逻辑仍允许某些额外字符；无解检测、自动洗牌和提示尚未实现。

本次发布使用独立分支 `release/desktop-v1.0`，不修改 main 或可视化开发分支。
